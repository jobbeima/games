# Color Match Web Version

This folder contains a browser version of the game.

## GitHub Pages

The repo now includes a GitHub Actions workflow that deploys this folder automatically.

### What you need to do
1. Create a GitHub repo for this project.
2. Push this project to the `main` branch.
3. In GitHub, open `Settings` -> `Pages`.
4. Set `Source` to `GitHub Actions`.

After the first push, GitHub will publish the site at:

`https://jobbeima.github.io/games/`

## Other hosts

You can also deploy `docs/` to Netlify or Vercel as a static site.
